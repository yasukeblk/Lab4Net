How a router chooses a route

How a router picks one route out of many

  • 3.1Routing-table interpretation
  • 3.2Forwarding decisions

Three questions, always in the same order

R1 can reach the server LAN 10.10.5.0/24 through R2 or through R3. When it has several routes that could carry a packet, it settles the choice with three rules, always in this order:

  1. Longest prefix match: the most specific route that contains the destination wins.
  2. Administrative distance (AD): for routes to the exact same prefix and length, the more trusted source wins.
  3. Metric: for routes from the same source to the same prefix, the lowest cost wins.

Most wrong exam answers come from applying these in the wrong order.

Reading the routing table

Each line of show ip route has a code for the source (C connected, L local, S static, O OSPF), the prefix, the brackets [AD/metric], and the next hop. O 10.10.5.0/24 [110/2] via 10.0.13.2 means: learned by OSPF (AD 110), total cost 2, send it to R3. show ip route 10.10.5.20 asks the router which single entry it would use for that address.

Metric: choosing within OSPF

OSPF adds up the cost of every outgoing interface on the way. At the start someone has set R1 G0/1 to cost 10, so the path through R2 costs 10 + 1 = 11 while the path through R3 costs 1 + 1 = 2. OSPF uses R3.

Setting ip ospf cost 50 on G0/2 makes the R3 path 51. Now R2 wins at 11, and OSPF moves the traffic without a single static route. Metric only compares routes from the same protocol; an OSPF cost means nothing to EIGRP or to a static route.

Longest prefix: the most specific route wins

A host route is a /32: it matches one address only. Security wants SRV1 (10.10.5.10) reached through R3, so R1 gets ip route 10.10.5.10 255.255.255.255 10.0.13.2.

Now 10.10.5.10 matches two routes: the static /32 and the OSPF /24. The router does not compare their AD, because they are different prefixes. The longer prefix, /32, wins. SRV2 (10.10.5.20) does not match the /32, so it keeps following OSPF through R2.

AD: only for the same prefix

The last change adds ip route 10.10.5.0 255.255.255.0 10.0.13.2 130. This /24 is the same prefix as the OSPF route, so now AD decides: OSPF 110 beats static 130. The static route is not installed; it waits as a floating backup and would only appear if OSPF lost the route.

Remember the defaults: connected 0, static 1, EIGRP 90, OSPF 110, RIP 120.

Check it worked

Use show ip route 10.10.5.10 and show ip route 10.10.5.20: each names the entry it matches. Trace from PC1 to both servers and you will see different second hops, 10.0.13.2 for SRV1 and 10.0.12.2 for SRV2. show ip route ospf shows the metric change from [110/2] to [110/11].

See it happen

In the app, these steps play out as packets moving across the lab's map.

  1. OSPF picks the cheaper path G0/1 has cost 10, so the R2 path costs 11 and the R3 path costs 2. R1 sends traffic for 10.10.5.20 through R3.
  2. The metric changes the path With ip ospf cost 50 on G0/2 the R3 path costs 51. Both are OSPF routes, so the lower metric wins and traffic moves to R2.
  3. A host route is more specific 10.10.5.10 matches the static /32 and the OSPF /24. Longest prefix is checked first, so the /32 via R3 wins without AD ever being compared.
  4. Other servers are unaffected 10.10.5.20 does not match the /32, so the only route that contains it is the OSPF /24, through R2.
  5. Same prefix, so AD decides The backup static /24 has AD 130. OSPF's /24 has AD 110 and wins, so the static route stays out of the table until OSPF loses the route.

Key terms

Longest prefix match
The rule that the route with the most network bits matching the destination is used first.
Host route
A /32 route that matches exactly one IPv4 address.
Administrative distance
A trust rating for a route source. Lower wins, but only between routes to the same prefix and length.
Metric
The cost of a route inside one routing protocol. OSPF uses cost, added up along the path.
OSPF cost
A per-interface value. By default reference bandwidth (100 Mbps) divided by interface bandwidth, minimum 1.
Prefix length
The number of network bits in a route, the /24 or /32.

For the exam

  • 3.1: interpret the routing table (protocol code, prefix, network mask, next hop, AD, metric, gateway of last resort). 3.2: longest prefix match, administrative distance, routing protocol metric.
  • Order of decision: longest prefix first, then AD, then metric.
  • A default route 0.0.0.0/0 is the shortest prefix of all, so it is used only when nothing more specific matches.
  • [110/11] is AD 110 and metric 11.
  • Exam questions often list several routes and ask which is used for one address: find every route that contains it, then take the longest.

Common mistakes

  • Choosing a route by its lower AD when the other route has a longer prefix: the /32 static would win even if it had AD 200.
  • Comparing an OSPF cost with an EIGRP metric: metrics only compare within one protocol.
  • Setting ip ospf cost on the far router and expecting R1 to change: OSPF uses the cost of the outgoing interface on each router along the path.
  • Expecting a backup static /24 with AD 130 to appear in the table while OSPF still has the /24.

Quick check

1. R1 has S 10.10.5.10/32 [1/0] and O 10.10.5.0/24 [110/11]. Which is used for 10.10.5.10?

  1. The OSPF /24, because it is a dynamic route
  2. The static /32, because it has the longer prefix
  3. The static /32, because AD 1 is lower than 110
  4. Both, shared equally
Show the answer

B. The static /32, because it has the longer prefix

Longest prefix is checked before AD. The /32 would win even with a higher AD. The AD answer gets the right route for the wrong reason.

2. R1 has an OSPF route to 10.10.5.0/24 and a static route to 10.10.5.0/24 with AD 130. Which is installed?

  1. The static route, because static routes always win
  2. Both, as equal-cost paths
  3. Neither, until one is removed
  4. The OSPF route, because 110 is lower than 130
Show the answer

D. The OSPF route, because 110 is lower than 130

Same prefix and length, so AD decides and 110 wins. The static route waits as a floating backup.

3. Two OSPF routes reach the same /24, one with cost 11 and one with cost 51. What does OSPF install?

  1. The cost 11 route
  2. The cost 51 route
  3. Both, load-balanced
  4. The route learned first
Show the answer

A. The cost 11 route

Within one protocol the lowest metric wins. Both routes would be installed only if their costs were equal.

4. A packet is for 10.10.5.20. The table has 0.0.0.0/0, 10.10.0.0/16 and 10.10.5.0/24. Which route is used?

  1. 0.0.0.0/0
  2. 10.10.0.0/16
  3. 10.10.5.0/24
  4. The one with the lowest AD
Show the answer

C. 10.10.5.0/24

All three contain the address. The /24 has the most matching bits, so it wins. The default route is only a last resort.
