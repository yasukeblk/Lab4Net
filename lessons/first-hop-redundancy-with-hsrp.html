First-hop redundancy with HSRP

How two routers share one gateway

  • 3.5First-hop redundancy

The problem: one gateway, two routers

A PC can have only one default gateway. The LAN has two routers to the core, R1 and R2, but if the PCs point at R1's address and R1 fails, they are cut off, even though R2 is right there. The PCs will not try another gateway on their own.

A first-hop redundancy protocol (FHRP) solves this. Two routers share a virtual IP address and a virtual MAC address. The PCs use the virtual IP as their gateway, and whichever router is in charge answers for it.

How HSRP works

HSRP (Hot Standby Router Protocol) is Cisco's FHRP. The routers in a group elect one active router, which forwards traffic for the virtual IP, and one standby router, which waits to take over.

  • The highest priority wins. The default is 100; if priorities tie, the highest interface IP wins.
  • Routers send hellos every 3 seconds. If the standby hears nothing for the hold time, 10 seconds, it becomes active.
  • For HSRP version 1, the virtual MAC is 0000.0C07.ACxx, where xx is the group number in hex. Group 1 is 0000.0C07.AC01.

Preempt

By default a router does not take the active role back once someone else holds it, even if its priority is higher. Preempt lets it do so. In this lab R1 has priority 110 and preempt, so when its link comes back it becomes active again. Without preempt, R2 would stay active until it failed itself.

Notice what HSRP watches: hellos on the LAN. If R1's uplink to CORE failed instead, its LAN side would stay up and it would stay active, sending traffic toward a dead link. Interface tracking, which lowers the priority when an uplink fails, exists for that, but it is beyond this lab.

How it is set up here

Both routers join group 1 on G0/0 with standby 1 ip 192.168.1.1. They keep their real addresses, 192.168.1.2 and 192.168.1.3. R1 adds standby 1 priority 110 and both add standby 1 preempt. The group number and virtual IP must match on both routers. The PCs keep 192.168.1.1 as their gateway and never change.

Other FHRPs

VRRP is the open standard version, with a master and backups instead of active and standby. GLBP is a Cisco protocol that can share traffic across several routers at once. HSRP uses one active router per group, so R2 carries no LAN traffic while R1 is up.

Check it worked

show standby brief lists the group, priority, the P flag for preempt, the state (Active or Standby), and the other router's address. R1 should be Active and R2 Standby. Shut R1 G0/0 and R2 becomes Active within the hold time. Pings from PC1 to 203.0.113.10 resume with no change on the PC.

See it happen

In the app, these steps play out as packets moving across the lab's map.

  1. The routers elect R1 and R2 exchange HSRP hellos every 3 seconds. R1 has priority 110 and R2 has 100, so R1 becomes active and R2 standby.
  2. PC1 looks for its gateway PC1 sends an ARP request for 192.168.1.1. Only the active router answers, with the virtual MAC 0000.0C07.AC01.
  3. Normal forwarding Traffic for 203.0.113.10 goes to the virtual MAC, which R1 owns. R1 forwards it through CORE to NET.
  4. R1's LAN link fails R1 G0/0 is shut down. R2 stops hearing R1's hellos.
  5. R2 takes over R2 becomes active and starts answering for 192.168.1.1 and the same virtual MAC. PC1 changes nothing.
  6. Traffic flows again PC1's traffic now leaves through R2 and CORE to NET.
  7. R1 comes back When G0/0 is back up, R1 hears R2 as active. With higher priority and preempt on, it takes the active role back.

Key terms

FHRP
First-hop redundancy protocol. Lets several routers act as one default gateway.
HSRP
Hot Standby Router Protocol, Cisco's FHRP with one active and one standby router per group.
Virtual IP
The shared gateway address that hosts use. Owned by whichever router is active.
Virtual MAC
The shared MAC address for the virtual IP. 0000.0C07.ACxx in HSRP version 1.
Active router
The HSRP router that forwards traffic for the virtual IP.
Standby router
The HSRP router that takes over if the active router fails.
Preempt
Lets a higher-priority router take the active role back when it returns.

For the exam

  • 3.5: describe the purpose, functions, and concepts of first hop redundancy protocols.
  • HSRP: active and standby, default priority 100, higher wins, preempt is off by default.
  • Hello 3 seconds, hold 10 seconds.
  • HSRPv1 virtual MAC 0000.0C07.ACxx, where xx is the group in hex.
  • HSRP and GLBP are Cisco protocols; VRRP is an open standard. GLBP load balances.

Common mistakes

  • Different virtual IPs or group numbers on the two routers: each believes it is alone, and both become active.
  • Setting a higher priority without preempt: the router does not take over again after a failure.
  • Using a router's real address as the PCs' gateway: the redundancy is there, but nobody uses it.
  • Assuming lower priority wins, as with some other protocols: in HSRP higher wins.

Quick check

1. R1 has HSRP priority 110 and R2 has the default. Neither has preempt. R1 reloads and comes back. Which router is active?

  1. R1, because 110 is higher
  2. R2, because preempt is off
  3. Both, until the hold time runs out
  4. Neither, until the PCs renew
Show the answer

B. R2, because preempt is off

Without preempt, a returning router does not take the role back even with a higher priority. R2 stays active.

2. What is the HSRP version 1 virtual MAC address for group 1?

  1. 0000.5E00.0101
  2. 0000.0C9F.F001
  3. 0000.0C07.AC01
  4. 0007.B400.0101
Show the answer

C. 0000.0C07.AC01

HSRPv1 uses 0000.0C07.ACxx with the group number in hex. 0000.0C9F.Fxxx is HSRPv2 and 0000.5E00.01xx is VRRP.

3. What default gateway do the PCs use in this lab?

  1. 192.168.1.1, the virtual IP
  2. 192.168.1.2, R1's real address
  3. 192.168.1.3, R2's real address
  4. Both real addresses, in turn
Show the answer

A. 192.168.1.1, the virtual IP

The PCs use the virtual IP. Whichever router is active answers for it, so the PCs never need to change.

4. Which FHRP is an open standard rather than Cisco proprietary?

  1. HSRP
  2. GLBP
  3. CDP
  4. VRRP
Show the answer

D. VRRP

VRRP is defined by the IETF. HSRP and GLBP are Cisco protocols, and CDP is not an FHRP.

5. What is the default HSRP hold time?

  1. 3 seconds
  2. 10 seconds
  3. 30 seconds
  4. 1 second
Show the answer

B. 10 seconds

Hellos are sent every 3 seconds and the hold time is 10. If the standby hears no hello for 10 seconds, it takes over.
