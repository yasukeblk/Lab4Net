Network components and topologies

What the boxes do and how networks are laid out

  • 1.1Network components
  • 1.2

Why the parts matter

A network is built from a small set of device types, each with one main job. If you know what each box does, you can read any network diagram and guess where a problem lives. The CCNA expects you to name each component, say what it does and know where it normally sits.

Moving traffic: switches and routers

  • A Layer 2 switch connects devices in the same network. It forwards Ethernet frames by MAC address (the hardware address burned into each network card). It keeps everything inside one subnet.
  • A router connects different networks. It forwards packets by IP address, using its routing table, and it is the default gateway that lets hosts leave their own subnet. Routers also connect sites across a WAN and to the internet.
  • A Layer 3 switch does both: it switches frames inside a VLAN and routes packets between VLANs in hardware, very fast. It usually has fewer WAN features than a router, so it routes inside a campus while routers handle the edge.

Protecting and serving

  • A firewall decides which traffic may pass between zones, such as inside and outside. It is stateful: it remembers connections started from inside and lets their replies back in. A next-generation firewall (NGFW) also recognises applications and users, not just ports, and often includes an IPS.
  • An IPS (intrusion prevention system) inspects traffic for known attack patterns (signatures) and drops matching traffic as it passes.
  • Endpoints are the devices people and things use: PCs, phones, printers, cameras. Servers provide services to them, such as files, web pages, DHCP or DNS.

Wireless and power

An access point (AP) connects wireless clients to the wired network. In a small site each AP is configured on its own (autonomous). In larger sites, lightweight APs are managed by a wireless LAN controller (WLC), which pushes one configuration to all of them and handles roaming. More generally, a controller is software that manages many devices from one place.

PoE (Power over Ethernet) sends electrical power down the same copper cable as the data. A PoE switch can power APs, IP phones and cameras without a power socket at each one. The standard 802.3af supplies up to 15.4 W per port, and 802.3at (PoE+) up to 30 W.

Campus designs: two-tier and three-tier

A campus network is built in layers.

  • Access layer: the switches end devices plug into. PoE and port security live here.
  • Distribution layer: aggregates the access switches, routes between VLANs and applies policy. It is usually built from Layer 3 switches.
  • Core layer: a fast backbone that connects the distribution blocks. Its only job is to move traffic quickly and reliably.

A three-tier design has all three. A smaller site merges core and distribution into one layer, called a collapsed core or two-tier design. Access switches connect up to two distribution switches, so losing one uplink does not cut them off.

Data centers, WANs and small offices

Spine-leaf is the data center design. Servers connect to leaf switches. Every leaf connects to every spine switch, but leaves never connect to each other and spines never connect to each other. Any server reaches any other server in the same number of hops (leaf, spine, leaf), so delay is predictable, and adding a spine adds capacity.

A WAN (wide area network) joins sites that are far apart, usually over links rented from a provider or over the internet. A SOHO (small office/home office) network often uses one box that is a router, switch, firewall and AP together.

On-premises or cloud

On-premises means the company owns the servers and runs them in its own building or data center. It buys hardware up front and its staff maintain it. Cloud means the servers belong to a provider and the company rents what it needs, reaching it over the internet or a private WAN link. Many networks are a mix of the two.

Key terms

Layer 2 switch
Forwards frames between devices in the same network, using MAC addresses.
Router
Forwards packets between networks, using IP addresses and a routing table.
Layer 3 switch
A switch that can also route between VLANs in hardware.
Next-generation firewall
A stateful firewall that also identifies applications and users and usually includes intrusion prevention.
IPS
Intrusion prevention system: inspects traffic inline and drops traffic that matches attack signatures.
Wireless LAN controller
A device that centrally configures and manages lightweight access points.
PoE
Power over Ethernet: power delivered over the data cable to devices such as APs and IP phones.
Collapsed core
A two-tier design where core and distribution are combined into one layer.
Spine-leaf
A data center design where every leaf switch connects to every spine switch and to nothing else in the fabric.

For the exam

  • 1.1: explain the role and function of network components. 1.2: describe characteristics of network topology architectures.
  • Routers separate networks and forward by IP; Layer 2 switches forward by MAC inside one network; Layer 3 switches do both.
  • Know the three campus layers and that two-tier merges core and distribution.
  • Spine-leaf: every leaf to every spine, no leaf-to-leaf and no spine-to-spine links; servers attach to leaves.
  • PoE: 802.3af up to 15.4 W per port, 802.3at (PoE+) up to 30 W.

Common mistakes

  • Thinking a switch can route between subnets: a Layer 2 switch cannot, so hosts in two VLANs cannot talk without a router or Layer 3 switch.
  • Cabling two leaf switches together in a spine-leaf design: it breaks the equal-hop rule the design depends on.
  • Plugging an AP or phone into a non-PoE port: the link is fine but the device never powers up.
  • Confusing an IDS with an IPS: an IDS only alerts on a copy of the traffic, an IPS sits inline and can drop it.

Quick check

1. Which device forwards traffic between two different IP subnets?

  1. A Layer 2 switch
  2. A router
  3. An access point
  4. A hub
Show the answer

B. A router

A router (or a Layer 3 switch) forwards packets between networks using IP addresses. A Layer 2 switch only forwards frames inside one network.

2. In a spine-leaf design, what does each leaf switch connect to?

  1. Only to its neighbouring leaf switches
  2. To one spine switch and its servers
  3. To every spine switch, and to its servers
  4. To the core layer, then to the spines
Show the answer

C. To every spine switch, and to its servers

Every leaf connects to every spine, and servers attach to leaves. Leaves do not link to each other, so any path is leaf, spine, leaf.

3. A small site has access switches and one pair of switches that act as both core and distribution. What is this design called?

  1. Spine-leaf
  2. Three-tier
  3. Point-to-point
  4. Collapsed core (two-tier)
Show the answer

D. Collapsed core (two-tier)

Merging core and distribution is a collapsed core, also called two-tier. Three-tier keeps them separate.

4. What does PoE let a switch do?

  1. Supply electrical power to devices over the Ethernet cable
  2. Route between VLANs
  3. Encrypt traffic between switches
  4. Increase the link speed to 10 Gbps
Show the answer

A. Supply electrical power to devices over the Ethernet cable

PoE carries power and data on the same copper cable, so APs, IP phones and cameras need no separate power supply.

5. Which component inspects traffic inline and drops packets that match known attack signatures?

  1. A wireless LAN controller
  2. A Layer 2 switch
  3. An IPS
  4. A DHCP server
Show the answer

C. An IPS

An intrusion prevention system sits in the traffic path and blocks matches. A next-generation firewall often includes one.
