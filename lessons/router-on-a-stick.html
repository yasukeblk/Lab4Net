Router-on-a-stick

How a router joins VLANs over one link

  • 2.1VLANs and inter-VLAN connectivity
  • 2.2Trunks and 802.1Q

The problem

Each VLAN is its own broadcast domain and its own subnet. Hosts in different VLANs cannot reach each other without a Layer 3 device, one that routes between subnets. The simple answer is one router port per VLAN, but routers have few ports and networks have many VLANs.

Router-on-a-stick uses one router port and one cable to the switch, configured as an 802.1Q trunk, so every VLAN arrives on the same link with its tag.

Subinterfaces

A subinterface is a logical interface carved out of a physical one, written with a dot: G0/0.10 and G0/0.20. Each acts like a separate router port.

  • encapsulation dot1q 10 ties G0/0.10 to frames tagged VLAN 10. The number after the dot is only a label; matching it to the VLAN is a convention that keeps things readable.
  • Then ip address 192.168.10.1 255.255.255.0. IOS refuses an address until the encapsulation is set.
  • The physical G0/0 gets no address but needs no shutdown. If the parent is down, every subinterface is down.

Each subinterface is a gateway

G0/0.10 (192.168.10.1) is the default gateway for VLAN 10, and G0/0.20 (192.168.20.1) for VLAN 20. As soon as both are up, R1 has two connected routes, marked C in the routing table, plus a local /32 route (L) for each of its own addresses. Connected routes are all it needs: both subnets are directly attached.

On the switch side, SW1 G0/1 must be a trunk, or the tagged frames have nowhere to go.

The journey of one packet

  1. PC1 (192.168.10.10) pings PC2 (192.168.20.10). The destination is outside its subnet, so PC1 sends the frame to its gateway, 192.168.10.1.
  2. SW1 receives it on a VLAN 10 access port and sends it up the trunk tagged 10.
  3. R1 accepts it on G0/0.10, looks up 192.168.20.10, and finds it connected on G0/0.20.
  4. R1 sends the packet back down the same cable, tagged 20.
  5. SW1 removes the tag and delivers it to PC2. The reply does the same in reverse.

Every inter-VLAN packet crosses the link twice, so the single link is shared and is a single point of failure. Larger networks route on a Layer 3 switch using SVIs instead.

The native VLAN on a router

Untagged frames on a trunk belong to the native VLAN. If the router needs an address in the native VLAN, its subinterface uses encapsulation dot1q 1 native (with the native VLAN number), so the router sends and accepts that VLAN untagged, matching the switch.

Check it worked

show ip route on R1 should show C routes for 192.168.10.0/24 via G0/0.10 and 192.168.20.0/24 via G0/0.20. show ip interface brief lists the subinterfaces as up up. On SW1, show interfaces trunk confirms G0/1 is trunking. Then ping PC2 from PC1.

See it happen

In the app, these steps play out as packets moving across the lab's map.

  1. Off-subnet, so to the gateway PC1 sees that 192.168.20.10 is outside 192.168.10.0/24, so it addresses the frame to its gateway, 192.168.10.1. It enters SW1 untagged on a VLAN 10 port.
  2. Up the trunk SW1 sends the frame up the trunk with an 802.1Q tag of 10. R1 hands it to G0/0.10, the subinterface with encapsulation dot1q 10.
  3. Routed and sent back down R1 finds 192.168.20.0/24 connected on G0/0.20. It sends the packet back down the same cable, now tagged 20.
  4. Delivered in VLAN 20 SW1 reads tag 20, removes it, and sends the frame out to PC2 in VLAN 20.
  5. The reply PC2 replies to its own gateway, 192.168.20.1. The packet goes up tagged 20 and comes back down tagged 10. The ping has crossed VLANs.
  6. If G0/0 is shut down Subinterfaces depend on the physical port. With G0/0 still shut down, both gateways are down and nothing crosses between VLANs.

Key terms

Inter-VLAN routing
Routing packets between hosts in different VLANs and subnets.
Router-on-a-stick
Inter-VLAN routing with one router port, trunked, using one subinterface per VLAN.
Subinterface
A logical interface on a physical port, such as G0/0.10, with its own address and VLAN.
encapsulation dot1q
The subinterface command that ties it to one 802.1Q VLAN tag.
Connected route
A route the router creates itself for a subnet on one of its up interfaces, marked C.
Default gateway
The router address a host sends to when the destination is outside its own subnet.

For the exam

  • 2.1: configure and verify VLANs, including InterVLAN connectivity. 2.2: trunk ports, 802.1Q and native VLAN.
  • The router side has subinterfaces with encapsulation dot1q; the switch side is a trunk.
  • The subinterface number does not have to equal the VLAN; the encapsulation line decides.
  • encapsulation dot1q N native sends that VLAN untagged on the router.
  • Each subinterface address is the default gateway for its VLAN and produces a connected route.

Common mistakes

  • Switch port to the router left as an access port: only one VLAN arrives, untagged, and none of the tagged subinterfaces receive anything.
  • Wrong VLAN in encapsulation dot1q: that VLAN's hosts cannot reach their gateway even though the address looks right.
  • Physical interface left shut down: every subinterface shows down.
  • PCs with the wrong default gateway: same-VLAN pings work, cross-VLAN pings fail.

Quick check

1. On G0/0.10 you type ip address 192.168.10.1 255.255.255.0 and IOS rejects it. What is missing?

  1. no shutdown on G0/0.10
  2. An address on G0/0
  3. A trunk on SW1
  4. encapsulation dot1q 10
Show the answer

D. encapsulation dot1q 10

A subinterface must be tied to a VLAN with encapsulation dot1q before IOS accepts an address on it.

2. What decides which VLAN subinterface G0/0.10 handles?

  1. The number after the dot
  2. The encapsulation dot1q command
  3. The IP address
  4. The switch access port
Show the answer

B. The encapsulation dot1q command

The number after the dot is only a name. The encapsulation line is what ties it to a tag; matching the two is just good practice.

3. What should PC1 use as its default gateway in this lab?

  1. 192.168.10.1
  2. 192.168.20.1
  3. The IP of SW1
  4. None, because it is on the same switch as PC2
Show the answer

A. 192.168.10.1

PC1 is in VLAN 10, so its gateway is the VLAN 10 subinterface address. Being on the same switch does not matter: PC2 is in a different subnet.

4. How must SW1 G0/1, the port facing R1, be configured?

  1. Access port in VLAN 10
  2. Access port in VLAN 1
  3. Trunk
  4. Routed port
Show the answer

C. Trunk

The link must carry both VLANs with their tags, so it must be a trunk.

5. G0/0.10 and G0/0.20 are configured, but G0/0 is still shut down. What state are the subinterfaces in?

  1. Up, because they have addresses
  2. Down, because the parent interface is down
  3. Up for VLAN 10 only
  4. Up, but with no routes
Show the answer

B. Down, because the parent interface is down

Subinterfaces follow their physical interface. A shut parent takes them all down.
