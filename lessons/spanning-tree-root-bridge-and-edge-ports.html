Spanning tree: root bridge and edge ports

How spanning tree stops switching loops

  • 2.5Rapid PVST+ interpretation

Why loops are deadly

Redundant links between switches are good: if one fails, another takes over. But they form a loop, and Ethernet frames carry no hop count to make them expire. A broadcast sent into the loop circles for ever and multiplies, a broadcast storm. Switches also keep relearning the same MAC address on different ports, and hosts receive duplicate frames. Within seconds the network stops.

STP (Spanning Tree Protocol) prevents this by putting one port in each loop into a blocking state, and unblocking it if an active link fails.

Electing the root bridge

Switches exchange BPDUs (bridge protocol data units). Each carries a bridge ID: a priority (32768 by default) plus the VLAN number, followed by the switch MAC address. Lowest bridge ID wins and becomes the root bridge. The root sends BPDUs every 2 seconds.

In this lab all three switches have priority 32769 for VLAN 1, so the tie goes to the lowest MAC: SW3 (000d.bd11.0a00), the oldest switch. Every path is then calculated toward SW3, which nobody chose.

Port roles

  1. Every non-root switch picks one root port: its port with the lowest total cost to the root. Default costs are 4 for 1 Gbps and 19 for 100 Mbps. Ties go to the lowest neighbour bridge ID, then the lowest port number.
  2. Every link gets one designated port, on the switch with the lower cost to the root (the lower bridge ID breaks a tie). All the root's own ports are designated.
  3. Any port left over is an alternate port. It discards frames, which breaks the loop.

Taking control of the election

spanning-tree vlan 1 root primary on SW1 sets its priority to 24576 (or lower, if needed to beat the current root). root secondary on SW2 sets 28672, so SW2 takes over if SW1 fails. SW3 keeps 32768.

Now SW1 is root and its ports are designated. SW2 and SW3 each reach it over one gigabit link, cost 4, so G0/1 is the root port on both. On the SW2-SW3 link the costs tie, and SW2 has the lower bridge ID, so SW2 G0/2 is designated and SW3 G0/2 is the alternate port that blocks.

Rapid PVST+

Cisco runs a separate tree per VLAN (PVST+). Classic STP moves a port through listening and learning, 15 seconds each, and can wait 20 seconds more before noticing a failure: 30 to 50 seconds. Rapid PVST+ (802.1w, per VLAN) uses only three states, discarding, learning and forwarding, and a quick handshake between switches, so it usually recovers in about a second. spanning-tree mode rapid-pvst turns it on.

Edge ports: PortFast and BPDU Guard

A port facing a PC cannot create a loop, so waiting is pointless. PortFast sends it straight to forwarding. Used on a port facing another switch, it can create a loop, so it is paired with BPDU Guard: if a BPDU arrives on that port, the switch puts it into the err-disabled state (shut down). shutdown then no shutdown brings it back once the cause is removed.

Check it worked

show spanning-tree shows the Root ID and this switch Bridge ID, and on SW1 the line This bridge is the root. Each port is listed with its role (Root, Desg, Altn) and status. Look on SW3 for G0/2 as Altn and blocking.

See it happen

In the app, these steps play out as packets moving across the lab's map.

  1. Root by accident With every priority at 32769, SW3 has the lowest MAC, so its BPDUs win and it becomes root. Nobody chose it.
  2. SW1 claims root After root primary, SW1 sends BPDUs with priority 24576 plus VLAN 1. That beats SW3, and SW2 accepts SW1 as root.
  3. SW3 follows SW3 also accepts SW1 as root. Its G0/1, cost 4 straight to SW1, becomes its root port.
  4. The loop is broken On the SW2-SW3 link both switches are cost 4 from the root. SW2 has the lower bridge ID (28672), so its end is designated and SW3 G0/2 becomes alternate and discards.
  5. Host port forwards at once PC1 connects to Fa0/1, an edge port with PortFast, so it forwards immediately instead of waiting.
  6. The path traffic takes PC1 to PC2 now goes SW1 to SW3 over G0/2 to G0/1. The blocked SW2-SW3 link carries nothing until another link fails.
  7. A switch on a desk port If someone swaps PC2 for a switch, its BPDUs arrive on Fa0/1. BPDU Guard err-disables the port and the topology stays as designed.

Key terms

STP
Spanning Tree Protocol: blocks redundant ports so a switched network has no loops.
BPDU
Bridge protocol data unit: the message switches use to run spanning tree.
Bridge ID
Priority plus VLAN number, then MAC address. The lowest is elected root.
Root bridge
The switch every other switch calculates its best path toward.
Root port
The port on a non-root switch with the best path to the root.
Designated port
The forwarding port on each link, on the switch closer to the root.
Alternate port
A port that discards frames to break a loop, ready to take over if the root port fails.
PortFast
Lets an edge port forward immediately instead of waiting.
BPDU Guard
Err-disables a port if a BPDU arrives on it.

For the exam

  • 2.5: interpret basic operations of Rapid PVST+: root port, root bridge (primary/secondary) and other port names, port states and roles, PortFast, root guard, loop guard, BPDU filter and BPDU guard.
  • Default priority is 32768, changed in steps of 4096. root primary gives 24576, root secondary 28672.
  • Lowest bridge ID wins. With equal priority the lowest MAC wins.
  • Default costs: 4 for 1 Gbps, 19 for 100 Mbps.
  • Rapid PVST+ states: discarding, learning, forwarding. Roles: root, designated, alternate, backup.

Common mistakes

  • Leaving every priority at default: an old, slow switch becomes root and traffic takes poor paths.
  • PortFast without BPDU Guard: a switch plugged into a desk port can create a loop.
  • Setting priority that is not a multiple of 4096: IOS rejects it.
  • Forgetting the tree is per VLAN: setting root for VLAN 1 does not change VLAN 10.

Quick check

1. All three switches have default priority. Which becomes root?

  1. The one with the highest MAC address
  2. The one with the most ports
  3. The one with the lowest MAC address
  4. The one switched on first
Show the answer

C. The one with the lowest MAC address

Lowest bridge ID wins, and with equal priorities the MAC address breaks the tie. That is why SW3, the oldest, wins.

2. What priority does spanning-tree vlan 1 root primary normally set?

  1. 24576
  2. 28672
  3. 32768
  4. 4096
Show the answer

A. 24576

Primary sets 24576 (or lower if another switch already beats that). 28672 is what secondary sets.

3. After the lab is configured, which port blocks?

  1. SW1 G0/1
  2. SW2 G0/2
  3. SW2 G0/1
  4. SW3 G0/2
Show the answer

D. SW3 G0/2

The root SW1 has only designated ports. On the SW2-SW3 link costs tie and SW2 has the lower bridge ID, so SW3 G0/2 is alternate.

4. A BPDU arrives on a port with BPDU Guard enabled. What happens?

  1. The BPDU is dropped and the port stays up
  2. The port is err-disabled
  3. The port becomes a root port
  4. PortFast is turned off on the port
Show the answer

B. The port is err-disabled

BPDU Guard shuts the port into err-disabled. Dropping BPDUs silently is what BPDU filter does, a different feature.

5. What is the default STP cost of a 1 Gbps link?

  1. 19
  2. 100
  3. 4
  4. 1
Show the answer

C. 4

4 for 1 Gbps and 19 for 100 Mbps. 1 is the OSPF cost of a gigabit link with the default reference bandwidth.
