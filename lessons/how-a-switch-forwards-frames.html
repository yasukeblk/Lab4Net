How a switch forwards frames

How a switch learns, forwards and floods

  • 1.13Switching concepts

The job of a switch

A switch connects devices on the same LAN and sends each Ethernet frame only where it needs to go. To do that it must know which port leads to which device. It works this out by itself, by watching traffic, and keeps the answers in its MAC address table (also called the CAM table).

Every Ethernet frame carries a destination MAC address and a source MAC address. A MAC address is 48 bits, written in hexadecimal, for example 0050.7966.6801. The first half is the OUI, which identifies the maker.

A frame is laid out as: destination MAC, source MAC, a type field saying what is inside (for example IPv4), the data, and a frame check sequence (FCS) at the end. The FCS lets the receiver detect damage. A switch that receives a frame with a bad FCS drops it rather than passing the damage on. The switch reads the MAC addresses but does not change them: the frame leaves exactly as it arrived.

Learning: reading the source

When a frame arrives, the switch looks at its source MAC address and the port it came in on, and records that pair in the table. It now knows that the device can be reached through that port. If the device moves to another port, the next frame it sends updates the entry.

Learning only ever uses the source address. A device that never sends anything is never learned.

Forwarding, filtering and flooding

Next the switch looks up the frame's destination MAC address:

  • Known unicast: the address is in the table. The switch forwards the frame out of that one port only.
  • Filtering: if the table says the destination is on the same port the frame arrived on, the switch drops it, because the device has already received it.
  • Unknown unicast: the address is not in the table. The switch floods the frame out of every port in the same VLAN except the one it arrived on. When the destination replies, its source address is learned, and later frames go to one port only.
  • Broadcast (FFFF.FFFF.FFFF): always flooded out of every port in the VLAN except the incoming one. ARP requests and DHCP Discovers are broadcasts.

Flooding stays inside the VLAN. A frame in VLAN 10 is never flooded to ports in VLAN 20.

A short example

  1. The table is empty. PC-A on port Fa0/1 sends a frame to PC-B.
  2. The switch learns PC-A is on Fa0/1. PC-B is unknown, so it floods the frame out of every other port in the VLAN.
  3. PC-B, on Fa0/2, replies to PC-A. The switch learns PC-B is on Fa0/2, finds PC-A in the table and forwards the reply out of Fa0/1 only.
  4. From now on, frames between the two go straight from port to port. Other devices no longer see them.

Aging

Each learned entry has a timer. If no frame is seen from that address for the aging time, the entry is removed. On Cisco switches the default is 300 seconds (5 minutes), changed with mac address-table aging-time. Aging keeps the table from filling with devices that have left, and lets moved devices be relearned. Every frame from a device resets its timer.

Entries you configure by hand are static and never age out.

Checking the table

show mac address-table lists each entry with its VLAN, MAC address, type (DYNAMIC or STATIC) and port. show mac address-table dynamic shows only learned entries, and you can filter by address or interface. show mac address-table aging-time shows the timer, and clear mac address-table dynamic empties the learned entries so the switch learns them again.

If many MAC addresses appear on one port, that port leads to another switch (or to a hub or AP), not to a single host.

Key terms

MAC address table
The switch's list of MAC addresses, each with the VLAN and port it was learned on. Also called the CAM table.
MAC learning
Recording a frame's source MAC address against the port it arrived on.
Unknown unicast
A frame whose destination MAC is not in the table; the switch floods it.
Flooding
Sending a frame out of every port in the VLAN except the one it arrived on.
Filtering
Dropping a frame whose destination is on the same port it came in on.
Aging time
How long a dynamic entry stays without new frames from that address; 300 seconds by default.
OUI
The first 24 bits of a MAC address, which identify the manufacturer.

For the exam

  • 1.13: describe switching concepts: MAC learning and aging, frame switching, frame flooding, MAC address table.
  • Switches learn from the source MAC and forward on the destination MAC.
  • Unknown unicast and broadcast frames are flooded out of all ports in the VLAN except the incoming port.
  • Default MAC aging time on Cisco switches is 300 seconds.
  • show mac address-table shows VLAN, MAC, type and port.

Common mistakes

  • Saying the switch learns from the destination address: it learns only from the source.
  • Expecting a silent device (a printer that never sends) to appear in the table: it shows up only after it sends a frame.
  • Thinking flooding crosses VLANs: it stays in the VLAN the frame belongs to.
  • Reading many MACs on one port as an attack: usually it is just an uplink to another switch.

Quick check

1. A frame arrives on Gi0/3. What does the switch do with the frame's source MAC address?

  1. Floods it to every port
  2. Records it in the MAC address table against Gi0/3
  3. Looks it up to decide where to forward
  4. Ignores it
Show the answer

B. Records it in the MAC address table against Gi0/3

Learning uses the source address and the incoming port. The destination address is what the switch looks up to forward.

2. The destination MAC of a unicast frame is not in the table. What does the switch do?

  1. Drops the frame
  2. Sends it to the default gateway
  3. Floods it out of all ports in the VLAN except the one it arrived on
  4. Sends an ARP request first
Show the answer

C. Floods it out of all ports in the VLAN except the one it arrived on

An unknown unicast is flooded within the VLAN. When the destination answers, the switch learns where it is.

3. What is the default MAC address table aging time on a Cisco switch?

  1. 30 seconds
  2. 5 minutes
  3. 4 hours
  4. Entries never age out
Show the answer

B. 5 minutes

Dynamic entries are removed after 300 seconds without a frame from that address. Static entries do not age.

4. A frame's destination MAC is in the table on the same port the frame arrived on. What happens?

  1. The switch filters (drops) the frame
  2. The switch floods the frame
  3. The switch forwards it back out of that port
  4. The switch removes the table entry
Show the answer

A. The switch filters (drops) the frame

The destination is on the segment the frame came from, so it has already received it. Sending it back would only duplicate it.
