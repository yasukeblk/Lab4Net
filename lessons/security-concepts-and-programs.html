Security concepts and programs

How networks are attacked and defended

  • 5.1
  • 5.2

The problem: networks are worth attacking

Networks carry money, health records and trade secrets, and businesses stop when they go down. Security aims to protect three things, often called the CIA triad: confidentiality (only the right people can read data), integrity (data is not changed without permission) and availability (systems are there when needed).

Four words to keep apart

  1. Vulnerability: a weakness. An unpatched router, a default password, an open telnet port.
  2. Threat: something or someone that could use the weakness to cause harm.
  3. Exploit: the actual method or tool that takes advantage of a vulnerability.
  4. Mitigation: a step that reduces the risk, such as patching, removing the default password or blocking the port.

A useful test: a vulnerability exists even if no one knows about it; an exploit is what turns it into an attack.

Mitigation rarely removes risk completely. It makes an attack harder, less likely or less damaging. A default password changed, an unused port shut down and a switch closet locked are each small mitigations; together they close most of the easy ways in.

Common attacks

  • Denial of service (DoS): flooding a target so real users cannot reach it. A DDoS uses many machines at once, often a botnet of infected devices.
  • Spoofing: faking an address. A forged source IP or MAC address lets an attacker hide or pose as another device.
  • Reflection and amplification: the attacker sends small requests with the victim's address spoofed as the source, so servers send large replies to the victim.
  • Man-in-the-middle: the attacker places itself between two parties, for example by ARP spoofing so traffic for the gateway goes to the attacker first.
  • Reconnaissance: scanning and gathering information before an attack.
  • Malware: a virus attaches to files and spreads when they are run; a worm spreads on its own across the network; a trojan hides inside software that looks useful.
  • Password attacks: guessing from a word list (dictionary) or trying every combination (brute force).
  • Buffer overflow: sending more data than a program expects, so it overwrites memory and crashes or runs the attacker's code.

Social engineering

Many attacks target people rather than devices. Phishing sends fake emails that lure people to give away passwords or open malware. Spear phishing targets particular people; whaling targets executives. Vishing uses phone calls and smishing uses text messages. A watering hole attack infects a website the targets are known to visit. Tailgating is following an authorised person through a secured door.

Defence in depth

No single control stops everything, so defences are layered. Examples covered in other lessons:

  • Firewalls and IPS to filter and inspect traffic at the edge.
  • ACLs on routers to limit which traffic and which hosts are allowed.
  • Port security, DHCP snooping and dynamic ARP inspection to stop spoofing on switch ports.
  • SSH and AAA so device access is encrypted and accountable.
  • Patching software and changing default passwords to remove known vulnerabilities.

A security program

Technology is only part of it. A security program is the organisation's plan for security, and the CCNA names three elements:

  1. User awareness: keeping everyone alert, for example with reminders or fake phishing emails that show people what to look for.
  2. User training: formal sessions that teach policies and safe practice, often tailored to the person's role.
  3. Physical access control: badges, locked wiring closets, cameras and mantraps (two-door entries that let one person through at a time). Anyone with a console cable and a few minutes alone with a router can take it over by password recovery.

The program also needs a written security policy that says what is allowed, who is responsible and what happens after an incident, so awareness, training and physical controls all point at the same rules.

Key terms

Vulnerability
A weakness in a system that could be used to cause harm.
Threat
A person or event with the potential to exploit a vulnerability.
Exploit
The method or tool that takes advantage of a vulnerability.
Mitigation
An action that reduces the likelihood or impact of an attack.
DDoS
A denial-of-service attack launched from many machines at once.
Man-in-the-middle
An attack in which the attacker secretly relays traffic between two parties.
Phishing
Fraudulent messages that trick people into revealing information or running malware.
Defence in depth
Layering several independent security controls.

For the exam

  • 5.1: define key security concepts (threats, vulnerabilities, exploits and mitigation techniques). 5.2: describe security program elements (user awareness, training and physical access control).
  • Be able to tell a vulnerability, a threat, an exploit and a mitigation apart in a short scenario.
  • Recognise attack types from a description: DoS/DDoS, spoofing, reflection and amplification, man-in-the-middle, reconnaissance, malware, password attacks.
  • Know the social engineering variants: phishing, spear phishing, whaling, vishing, smishing, watering hole, tailgating.
  • User awareness is ongoing and informal; training is formal; physical access control protects the equipment itself.

Common mistakes

  • Calling a missing patch a threat: it is a vulnerability. The attacker who would use it is the threat.
  • Confusing a virus with a worm: a worm spreads by itself; a virus needs someone to run the infected file.
  • Securing the CLI but leaving the wiring closet unlocked: physical access allows password recovery.
  • Treating one firewall as enough: once something gets past it, nothing inside stops it.

Quick check

1. A router runs software with a known flaw that has not been patched. What is the flaw?

  1. A threat
  2. A vulnerability
  3. An exploit
  4. A mitigation
Show the answer

B. A vulnerability

The flaw is a weakness, which is a vulnerability. The attacker is the threat, the attack code is the exploit, and installing the patch is the mitigation.

2. Small requests are sent to many servers with the victim's address as the source, and the servers send large replies to the victim. What is this?

  1. A man-in-the-middle attack
  2. A trojan
  3. A reflection and amplification attack
  4. A dictionary attack
Show the answer

C. A reflection and amplification attack

Spoofing the victim as the source makes the servers reflect replies to it, and the replies are larger than the requests, so the traffic is amplified.

3. Which malware spreads across a network on its own without a user running anything?

  1. A worm
  2. A virus
  3. A trojan
  4. Phishing
Show the answer

A. A worm

A worm copies itself across the network by itself. A virus needs an infected file to be run, and a trojan relies on the user installing it.

4. A company sends staff fake phishing emails and shows those who clicked what they missed. Which security program element is this?

  1. Physical access control
  2. Accounting
  3. Defence in depth
  4. User awareness
Show the answer

D. User awareness

Ongoing reminders and simulated phishing build user awareness. Formal classes would be training.

5. Someone follows an employee through a badge-controlled door without using their own badge. What is this called?

  1. Vishing
  2. Tailgating
  3. Spoofing
  4. Whaling
Show the answer

B. Tailgating

Tailgating is following an authorised person through a secured entry. Mantraps are one physical control that stops it.
