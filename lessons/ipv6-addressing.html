IPv6 addressing

How IPv6 addresses are built

  • 1.8IPv6 addressing and prefixes
  • 1.9IPv6 address types

What an IPv6 address looks like

An IPv6 address is 128 bits, written as eight groups of four hex digits separated by colons. Two rules shorten it:

  1. Leading zeros in a group can be dropped: 0DB8 becomes DB8.
  2. One run of all-zero groups can become ::, once per address.

So 2001:0DB8:ACAD:0001:0000:0000:0000:0001 is written 2001:DB8:ACAD:1::1. On a LAN the first 64 bits are the prefix (the network) and the last 64 are the interface ID (the host).

The address types you need

  • Global unicast (2000::/3): routable everywhere, like a public IPv4 address. 2001:DB8::/32 is reserved for examples like this lab.
  • Link-local (FE80::/10): valid only on one link and never routed. Every IPv6 interface has one.
  • Unique local (FC00::/7): private addresses, like 10.0.0.0/8.
  • Multicast (FF00::/8): one to many. IPv6 has no broadcast at all.
  • Loopback ::1, and unspecified :: for "no address yet".

R1's addresses

IPv6 routing is off on a Cisco router until ipv6 unicast-routing. Without it R1 will not forward IPv6 or send router advertisements.

On G0/0, R1 gets 2001:DB8:ACAD:1::1/64 typed in full. On G0/1, eui-64 gives only the prefix and lets R1 build the interface ID itself. Both interfaces also get the link-local address FE80::1. That is allowed, because link-local addresses only need to be unique on their own link, and it makes the gateway easy to type.

EUI-64: an interface ID from a MAC

A MAC address is 48 bits; an interface ID is 64. EUI-64 fills the gap:

  1. Split the MAC in half: 00E0.B0 | 63.3710.
  2. Insert FFFE in the middle: 00E0:B0FF:FE63:3710.
  3. Flip the seventh bit of the first byte: 00 becomes 02.

The result is 02E0:B0FF:FE63:3710. show ipv6 interface marks such an address with [EUI]. Because the MAC is on R1 G0/1, you only find out its global address after configuring it, which is why the lab asks you to look it up.

SLAAC: hosts configure themselves

With SLAAC (stateless address autoconfiguration), a host needs no DHCP server. It sends a Router Solicitation to FF02::2, all routers. R1 answers with a Router Advertisement carrying the /64 prefix. The host adds its own interface ID (EUI-64 in this lab) and uses R1's link-local address, FE80::1, as its default gateway. R1 also sends advertisements on its own every few minutes.

Before using a new address, the host checks nobody else has it, with duplicate address detection. Router Solicitation, Router Advertisement and the neighbor messages that replace ARP are all ICMPv6 messages, together called Neighbor Discovery Protocol (NDP). Many real Windows hosts use a random interface ID instead of EUI-64, for privacy; the prefix still comes from the advertisement.

Multicast groups and checking

Every IPv6 interface joins FF02::1 (all nodes); a router also joins FF02::2 (all routers). Each unicast address adds a solicited-node group, FF02::1:FF plus the last 24 bits of the address. Neighbor Discovery uses it to find a MAC address, the job ARP does in IPv4. Check with show ipv6 interface brief, then show ipv6 interface g0/1 for the [EUI] address and the groups joined.

See it happen

In the app, these steps play out as packets moving across the lab's map.

  1. PC1 asks for a router PC1 has only its own link-local address. It sends a Router Solicitation to FF02::2, the all-routers group.
  2. R1 advertises the prefix R1 replies with a Router Advertisement: the prefix is 2001:DB8:ACAD:1::/64 and the gateway is FE80::1.
  3. PC1 builds its address PC1 adds an EUI-64 interface ID from MAC 00E0.B063.3710, giving 2001:DB8:ACAD:1:2E0:B0FF:FE63:3710. No DHCP server was needed.
  4. PC1 pings the server PC1 sends to 2001:DB8:ACAD:2::10 through its gateway. R1 has both prefixes as connected routes and forwards the packet onto LAN 2.
  5. The reply comes back PC2 has a fixed address and FE80::1 as its gateway, so its reply goes to R1 and back to PC1.

Key terms

Global unicast address
A routable IPv6 address from 2000::/3.
Link-local address
An FE80::/10 address valid only on one link. Used as next hop and gateway.
Prefix
The network part of an IPv6 address, written with a length such as /64.
Interface ID
The host part of an IPv6 address, normally the last 64 bits.
EUI-64
A way to build a 64-bit interface ID from a 48-bit MAC by inserting FFFE and flipping the seventh bit.
SLAAC
Stateless address autoconfiguration. A host builds its own address from a router advertisement.
Solicited-node multicast
FF02::1:FF plus the last 24 bits of an address. Used by Neighbor Discovery instead of ARP broadcasts.

For the exam

  • 1.8: configure and verify IPv6 addressing and prefix. 1.9: describe IPv6 address types: unicast (global, unique local, link local), anycast, multicast, modified EUI-64.
  • Abbreviate and expand addresses: drop leading zeros, and use :: only once.
  • Know the prefixes: 2000::/3, FE80::/10, FC00::/7, FF00::/8.
  • Work EUI-64 by hand, including flipping the seventh bit.
  • IPv6 has no broadcast. RS goes to FF02::2, and unsolicited RAs go to FF02::1.

Common mistakes

  • Using :: twice in one address: it becomes impossible to tell how many zeros each one stands for.
  • Forgetting ipv6 unicast-routing: interfaces have addresses, but hosts get no router advertisements and nothing is forwarded.
  • Forgetting to flip the seventh bit when working out an EUI-64 address.
  • Expecting a link-local address to be reachable from another subnet: it never leaves its link.

Quick check

1. Which is a valid shortened form of 2001:0DB8:0000:0000:0001:0000:0000:0010?

  1. 2001:DB8::1::10
  2. 2001:DB8::1:0:0:10
  3. 2001:DB8:0:0:1::1
  4. 2001:DB8::1:0:0:1
Show the answer

B. 2001:DB8::1:0:0:10

:: can appear only once, so one zero run is collapsed and the other kept as 0:0. Leading zeros can drop, but trailing ones cannot: 0010 is 10, not 1.

2. What is the EUI-64 interface ID for MAC 00E0.B063.3710?

  1. 00E0:B0FF:FE63:3710
  2. 02E0:B063:FFFE:3710
  3. 00E0:B0FE:FF63:3710
  4. 02E0:B0FF:FE63:3710
Show the answer

D. 02E0:B0FF:FE63:3710

Split the MAC, insert FFFE, then flip the seventh bit: 00 becomes 02.

3. Which address range is link-local?

  1. FE80::/10
  2. FC00::/7
  3. FF00::/8
  4. 2000::/3
Show the answer

A. FE80::/10

FE80::/10 is link-local. FC00::/7 is unique local, FF00::/8 multicast and 2000::/3 global unicast.

4. PC1 used SLAAC. Where did its default gateway come from?

  1. A DHCPv6 server
  2. The Router Advertisement, which gives R1's link-local address
  3. Its own EUI-64 calculation
  4. A broadcast from R1
Show the answer

B. The Router Advertisement, which gives R1's link-local address

The RA's source is R1's link-local address, and the host uses it as its gateway. IPv6 has no broadcast.

5. Why can R1 use FE80::1 on both G0/0 and G0/1?

  1. Link-local addresses only need to be unique on their own link
  2. Because it uses EUI-64
  3. IOS ignores duplicates on routers
  4. FE80::1 is a multicast address
Show the answer

A. Link-local addresses only need to be unique on their own link

A link-local address is never routed, so the same one can appear on every link of the router.
