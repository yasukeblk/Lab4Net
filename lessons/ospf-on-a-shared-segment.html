OSPF on a shared segment

How OSPF picks a DR on a shared LAN

  • 3.4Single-area OSPFv2

The problem: too many neighbours

OSPF routers become neighbours by exchanging Hello messages, then form an adjacency: they swap their whole link-state database and keep it in sync. On a link with two routers that is one adjacency. On one Ethernet segment with four routers (R1 to R4 on 10.0.0.0/24), full adjacencies between every pair would be six, and every change would be flooded by everyone to everyone.

OSPF fixes this on broadcast networks such as Ethernet by electing a Designated Router (DR) and a Backup DR (BDR).

What the DR does

  1. Every router forms a full adjacency with the DR and the BDR only.
  2. A router with news sends it to 224.0.0.6, the address only the DR and BDR listen to.
  3. The DR floods it to everyone on 224.0.0.5, the all-OSPF-routers address.
  4. The BDR listens to everything, ready to take over at once if the DR fails.

Routers that are neither are called DROTHERs. Two DROTHERs stop at the 2-Way state with each other. That is normal, not a fault. In this lab R3 sees R4 as 2WAY for exactly this reason.

How the election works

Each router's interface has an OSPF priority, 0 to 255, default 1. The highest priority becomes DR, the next highest BDR. If priorities tie, the highest router ID wins. Priority 0 means the router never takes either role.

There is no pre-emption. Once a DR and BDR exist, a router that arrives later or raises its priority does not take over. That is why giving R4 priority 255 and R3 priority 100 changes nothing at first. When a DR leaves, the BDR is promoted and a new BDR is elected.

Moving the roles here

R1 is DR and R2 is BDR because they booted first. Setting ip ospf priority 0 on R1's G0/0 removes it from the roles: R2 is promoted to DR and R4, with the highest priority left, becomes BDR. Doing the same on R2 promotes R4 to DR, and R3 becomes BDR. The election is per interface, so the command goes on G0/0, the shared LAN.

Point-to-point links and cost

The WAN link R4 to BR has only two routers, so a DR adds nothing. ip ospf network point-to-point on both ends skips the election, the adjacency forms faster, and the neighbour shows as FULL/ -. Both ends must agree, or the hello settings do not match.

OSPF cost is reference bandwidth (default 100 Mbps) divided by the interface bandwidth, minimum 1. G0/1 is a gigabit port, so OSPF sees cost 1 even though the circuit behind it is only 10 Mbps. Setting ip ospf cost 10 on both ends makes BR's metric to 10.0.0.0/24 10 + 1 = 11.

Check it worked

show ip ospf neighbor lists each neighbour's state and role: FULL/DR, FULL/BDR, 2WAY/DROTHER, or FULL/ - on point-to-point. show ip ospf interface brief shows each interface's role, cost and neighbour count. show ip ospf interface g0/0 names the DR and BDR by router ID and address, and the network type.

See it happen

In the app, these steps play out as packets moving across the lab's map.

  1. Hellos find the neighbours Every router sends hellos to 224.0.0.5 every 10 seconds. Through SW1, all four routers on 10.0.0.0/24 see each other.
  2. News goes to the DR R1 is DR because it booted first. When R3 has a change it sends it to 224.0.0.6, which only the DR and BDR hear.
  3. The DR floods it R1 repeats the update to 224.0.0.5 so every router hears it once. R3 and R4 never exchange databases directly, so they stay 2WAY.
  4. R1 gives up the role With priority 0 on R1 G0/0, R1 drops out. BDR R2 is promoted to DR and R4, now the highest priority left, becomes BDR.
  5. The roles land where planned Priority 0 on R2 removes it too. R4 is promoted to DR and R3, at priority 100, is elected BDR.
  6. No election on point-to-point With network type point-to-point on both ends, R4 and BR skip the election and go straight to FULL. The cost of 10 reflects the slow circuit.
  7. Roles change, reachability does not PC1 pings R1. BR reaches 10.0.0.0/24 with metric 11, and the new DR and BDR made no difference to the path.

Key terms

Designated Router (DR)
The router on a broadcast segment that every other router forms a full adjacency with and that floods updates to all.
Backup DR (BDR)
Keeps full adjacencies like the DR and takes over if the DR fails.
DROTHER
A router on the segment that is neither DR nor BDR.
OSPF priority
A per-interface value 0 to 255, default 1. Highest wins the election; 0 means never DR or BDR.
Router ID
A 32-bit OSPF name written like an IPv4 address. Breaks ties in the election.
2-Way
The neighbour state where each router has seen itself in the other's hello. Final state between two DROTHERs.
Network type
How OSPF treats a link: broadcast (with a DR) or point-to-point (no DR).

For the exam

  • 3.4: configure and verify single-area OSPFv2: neighbor adjacencies, point-to-point, broadcast (DR/BDR selection), router ID.
  • DR election: highest priority, then highest router ID. Default priority 1; 0 means ineligible.
  • No pre-emption: a better router does not take over from a working DR.
  • Multicast: 224.0.0.5 all OSPF routers, 224.0.0.6 DR and BDR.
  • Default hello 10 seconds and dead 40 seconds on broadcast and point-to-point links. Hello and dead timers must match for routers to become neighbours.

Common mistakes

  • Raising a priority and expecting the DR to change at once: nothing moves until the DR or BDR goes away.
  • Setting priority in router configuration mode: it is an interface command.
  • Treating 2WAY between DROTHERs as a broken adjacency.
  • Point-to-point on one end only: the network types differ and the routers may not form a working adjacency.
  • Leaving a slow circuit on a gigabit port at the default cost of 1, so OSPF prefers it over better paths.

Quick check

1. R1 is DR. You set R4's priority to 255. What happens?

  1. R4 becomes DR at once
  2. R4 becomes BDR at once
  3. Nothing until the current DR or BDR goes away
  4. R1 and R4 share the DR role
Show the answer

C. Nothing until the current DR or BDR goes away

OSPF has no pre-emption. A higher priority only matters at the next election.

2. R3 and R4 are both DROTHERs on the same LAN. What neighbour state do they show for each other?

  1. FULL
  2. 2WAY
  3. EXSTART
  4. INIT
Show the answer

B. 2WAY

DROTHERs only form full adjacencies with the DR and BDR. With each other they stop at 2-Way, which is normal.

3. Two routers both have priority 1. Which becomes DR?

  1. The one with the lowest router ID
  2. The one with the lowest interface address
  3. The one with the most neighbours
  4. The one with the highest router ID
Show the answer

D. The one with the highest router ID

Equal priorities are broken by the highest router ID.

4. A gigabit interface runs over a 10 Mbps circuit. With default settings, what OSPF cost does it get?

  1. 1
  2. 10
  3. 100
  4. 1000
Show the answer

A. 1

Cost is 100 Mbps divided by interface bandwidth, minimum 1. OSPF sees the gigabit port, not the circuit, so it gets 1. That is why you set the cost by hand.

5. Which address does a DROTHER send its link-state updates to on a broadcast segment?

  1. 224.0.0.5
  2. 224.0.0.6
  3. 255.255.255.255
  4. The DR's unicast address only
Show the answer

B. 224.0.0.6

224.0.0.6 reaches only the DR and BDR. The DR then floods to 224.0.0.5, all OSPF routers.
