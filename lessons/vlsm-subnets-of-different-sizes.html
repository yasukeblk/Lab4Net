VLSM: subnets of different sizes

How to fit subnets to the hosts you have

  • CCNA 1.6IPv4 addressing and subnetting

The problem with one size

Suppose every subnet in a company is a /24. A link between two routers needs 2 addresses and gets 254. A floor with 300 users does not fit at all. Using one mask everywhere wastes addresses in some places and runs out in others.

VLSM (variable-length subnet masking) means using different prefix lengths inside the same address block, so each subnet is as big as it needs to be and no bigger.

The method

  1. List every subnet you need and how many hosts each must hold. Include the links between routers.
  2. Sort the list from largest to smallest.
  3. For each one, pick the smallest subnet that fits (hosts + 2, rounded up to a power of two).
  4. Give it the next free block. Then move on to the next one.

Working from largest to smallest matters. A subnet has to start on a multiple of its own block size. Placing the big ones first keeps every start address on a valid boundary and leaves no gaps.

A worked example

You have 192.168.1.0/24 and need: a LAN of 100 hosts, a LAN of 50, a LAN of 20, and two router-to-router links.

  1. 100 hosts: needs 128 addresses, a /25. Takes 192.168.1.0/25, which is .0 to .127.
  2. 50 hosts: needs 64 addresses, a /26. Next free is .128. Takes 192.168.1.128/26, which is .128 to .191.
  3. 20 hosts: needs 32 addresses, a /27. Next free is .192. Takes 192.168.1.192/27, which is .192 to .223.
  4. Link 1: needs 4 addresses, a /30. Takes 192.168.1.224/30, which is .224 to .227.
  5. Link 2: another /30. Takes 192.168.1.228/30, which is .228 to .231.

Addresses .232 to .255 are still free for later. With /26 everywhere you would have had only four subnets, and the 100-host LAN would not fit.

Checking for overlap

The one rule VLSM must not break: no two subnets may share an address. To check a design, write each subnet as a first and last address and make sure the ranges do not cross.

For example 192.168.1.128/26 runs from .128 to .191. A second subnet of 192.168.1.160/27 runs from .160 to .191. It sits inside the first one, so the design is wrong. A router will refuse the second address with an overlaps error if both are on its own interfaces. If they are on different routers nothing complains, and traffic goes to the wrong place.

What makes VLSM work

Routers can only use subnets of different sizes if every route carries its own mask. That is called classless routing. OSPF, EIGRP and static routes all carry the mask. This is why every route in show ip route is shown with a prefix length, and why the heading says a network is variably subnetted when it holds subnets of more than one size.

A router picks the route with the longest prefix match, so a /30 link and the /24 around it can both be in the table without confusion.

Point-to-point links

A link between two routers has exactly two devices on it. A /30 gives 4 addresses: network, two hosts, broadcast. That is the classic choice and the one to expect in exam scenarios.

A /31 has only 2 addresses and no network or broadcast address. Cisco routers accept it on point-to-point links and warn you when you configure it. Know that it exists; use /30 unless a question says otherwise.

Key terms

VLSM
Variable-length subnet masking: using more than one prefix length inside the same address block.
Classless routing
Routing in which every route carries its own mask, so subnets of any size can be mixed.
Overlap
Two subnets whose address ranges share one or more addresses.
Longest prefix match
The rule that a router uses the matching route with the most network bits.
Point-to-point link
A link with exactly two devices, normally addressed with a /30.
Variably subnetted
The routing table heading for a network that contains subnets with different masks.

For the exam

  • 1.6: configure and verify IPv4 addressing and subnetting. VLSM questions usually ask which subnet to assign next, or which address plan wastes the fewest addresses.
  • Always allocate the largest subnet first.
  • A /30 has 2 usable hosts and is the standard answer for a router-to-router link.
  • A subnet must start on a multiple of its block size. 192.168.1.100/26 is not a network address; 192.168.1.64/26 is.

Common mistakes

  • Allocating small subnets first, then finding the big one has no aligned block left.
  • Starting a subnet at the next free address without checking the boundary. A /26 cannot start at .32.
  • Giving two sites subnets that overlap. Each router looks fine on its own, but hosts in the shared range are unreachable from elsewhere.

Quick check

1. When planning with VLSM, which subnet should be allocated first?

  1. The one with the fewest hosts
  2. The router-to-router links
  3. The one with the most hosts
  4. The one closest to the internet
Show the answer

C. The one with the most hosts

Largest first. Big blocks need to start on big boundaries, and placing them first keeps everything aligned with no gaps.

2. 192.168.1.0/25 is in use. Which of these can be assigned next without overlapping it?

  1. 192.168.1.128/26
  2. 192.168.1.64/26
  3. 192.168.1.0/26
  4. 192.168.1.96/27
Show the answer

A. 192.168.1.128/26

192.168.1.0/25 covers .0 to .127. The other three options all fall inside that range. 192.168.1.128/26 covers .128 to .191.

3. What is the most efficient mask for a link between two routers on this exam?

  1. 255.255.255.0
  2. 255.255.255.248
  3. 255.255.255.240
  4. 255.255.255.252
Show the answer

D. 255.255.255.252

255.255.255.252 is /30: 4 addresses, 2 usable. A /29 would waste four more addresses on each link.

4. Why must a routing protocol be classless for VLSM to work?

  1. It must send the mask with each route
  2. It must use multicast updates
  3. It must support IPv6
  4. It must run on every interface
Show the answer

A. It must send the mask with each route

With different subnet sizes in use, a router cannot guess the mask from the address. Each route has to carry its own prefix length.

5. A LAN needs 28 hosts and the next free address is 10.1.1.64. Which subnet should it get?

  1. 10.1.1.64/28
  2. 10.1.1.64/27
  3. 10.1.1.64/26
  4. 10.1.1.72/27
Show the answer

B. 10.1.1.64/27

28 + 2 = 30, so 32 addresses, a /27. .64 is a multiple of 32, so 10.1.1.64/27 is valid and runs to .95. A /28 holds only 14 hosts, and .72 is not a /27 boundary.
