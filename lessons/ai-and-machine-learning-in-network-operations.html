AI and machine learning in network operations

How AI and machine learning help run networks

  • 6.4

The problem: too much data

A modern network produces a huge amount of operational data: interface counters, syslog messages, SNMP values, flow records, wireless client statistics. No person can read all of it. Problems hide in the noise, and by the time someone notices, users have already complained.

AI (artificial intelligence) and machine learning help by finding patterns in that data, spotting what is unusual, and increasingly by answering questions in plain language. Using these tools to run IT operations is often called AIOps.

What machine learning is

In ordinary software, a person writes the rules: if CPU is above 90 percent, raise an alarm. In machine learning (ML), the system learns patterns from data instead. The result is called a model.

  • Supervised learning trains on labelled examples, where the right answer is already known, such as past events marked as real faults or false alarms.
  • Unsupervised learning finds structure in data with no labels, such as grouping similar devices or spotting values that do not fit.
  • Reinforcement learning learns by trial and reward, improving actions over time.

Models are only as good as the data they learn from. Poor or unrepresentative data gives poor results.

Predictive AI

Predictive AI uses historical and live data to forecast what is likely to happen or to recognise what is abnormal. In network operations it is used for:

  • Baselining: learning what normal looks like for this network at this time of day, instead of using one fixed threshold.
  • Anomaly detection: flagging behaviour that differs from the baseline, such as a sudden rise in failed wireless logins.
  • Forecasting: predicting when a link will run out of capacity or a component is likely to fail, so it can be fixed before users notice.
  • Root cause analysis: linking many alarms that come from one underlying fault.

Generative AI

Generative AI creates new content, such as text or code, in response to a prompt. It is usually built on a large language model (LLM) trained on very large amounts of text. In network operations it can:

  • Answer questions about the network in plain language, such as which sites had the most problems last week.
  • Draft configurations, scripts or documentation.
  • Summarise long logs or troubleshooting output.

Vendors, Cisco included, are building such assistants into their management platforms.

Limits and risks

  • Generative AI can produce answers that sound confident but are wrong, called hallucinations. A generated configuration must be reviewed and tested before it is applied.
  • Sending configurations or logs to an outside AI service may expose sensitive data, such as addresses, passwords or customer details.
  • Predictive models can raise false alarms or miss real problems if the network changes and the model is not retrained.

The usual approach keeps a human in the loop: AI suggests and explains, and an engineer decides and approves the change.

Where it fits

AI works on top of the automation and controller ideas in the rest of section 6. Controllers collect the data through their southbound connections and telemetry, AI finds the patterns, and the controller or automation tools carry out the fix. This joins up into a loop of collect, analyse, act and verify.

An example: users at one site report slow wireless. Instead of an engineer reading logs from every access point, the assurance tool has already noticed that failed client logins at that site rose well above their usual level, linked them to one overloaded authentication server, and shown the likely cause. A generative assistant can then explain the finding in plain language and suggest a fix, which the engineer checks before anything changes.

Key terms

Artificial intelligence
Computer systems that perform tasks that normally need human judgement.
Machine learning
Systems that learn patterns from data to build a model, instead of following hand-written rules.
Model
What a machine learning system produces from its training data and then uses on new data.
Predictive AI
AI that forecasts outcomes or detects anomalies from past and current data.
Generative AI
AI that creates new content, such as text or configuration, from a prompt.
Large language model
A generative model trained on very large amounts of text.
Baseline
The learned picture of normal behaviour that new data is compared against.
Hallucination
A confident but wrong answer from a generative AI model.

For the exam

  • 6.4: explain AI (generative and predictive) and machine learning in network operations.
  • Predictive AI forecasts and detects anomalies from historical data. Generative AI creates new content from a prompt.
  • Supervised learning uses labelled data. Unsupervised learning finds patterns in unlabelled data.
  • Dynamic baselines replace fixed thresholds, which reduces false alarms.
  • Generated output must be verified by a person before it is applied to the network.

Common mistakes

  • Treating predictive and generative AI as the same thing: one forecasts and flags, the other writes new content.
  • Pasting a generated configuration straight into production: a hallucinated command can break the network or open a security hole.
  • Assuming a model stays accurate for ever: when the network changes, the baseline must be relearned.
  • Sending real configurations with secrets to a public AI service without approval: that can leak passwords and addresses.

Quick check

1. A tool learns normal traffic levels for each link and alerts when a link behaves unusually. What kind of AI is this?

  1. Generative AI
  2. Predictive AI
  3. A large language model writing configuration
  4. Manual threshold alerting
Show the answer

B. Predictive AI

Learning a baseline and detecting anomalies is predictive AI. Generative AI creates new content, and a fixed threshold is not learning at all.

2. An engineer asks an assistant to write an OSPF configuration for a new branch. What kind of AI is doing this?

  1. Unsupervised learning
  2. Predictive AI
  3. Generative AI
  4. Anomaly detection
Show the answer

C. Generative AI

Creating new text, such as configuration, from a prompt is generative AI. The output must still be checked before use.

3. What is the difference between supervised and unsupervised learning?

  1. Supervised needs a person watching it run
  2. Unsupervised only works on wireless data
  3. Supervised learning cannot be used for networks
  4. Supervised trains on labelled examples, unsupervised finds patterns in unlabelled data
Show the answer

D. Supervised trains on labelled examples, unsupervised finds patterns in unlabelled data

The difference is the training data. Labelled examples mean the right answer is known in advance. Unsupervised learning has to find structure on its own.

4. Why should generated configuration be reviewed before it is applied?

  1. Generative AI can produce wrong output that looks correct
  2. Generative AI only produces JSON
  3. Configurations created by AI cannot be saved
  4. Review is only needed for predictive AI
Show the answer

A. Generative AI can produce wrong output that looks correct

Generative models can hallucinate commands or settings. A human review and a test keep a confident but wrong answer off the production network.
