Subnetting questions the exam asks

How to answer any subnetting question

  • CCNA 1.6IPv4 addressing and subnetting

One method, five questions

Subnetting questions come in a few shapes. All of them are answered with the same three numbers: the mask value in the interesting octet, the block size (256 minus that value) and the host bits (32 minus the prefix).

This lesson works one example of each shape. Cover the answers and try each one first.

1. Which subnet is this host in?

Take 172.16.77.200/20.

  1. /20 is 16 bits plus 4. Four bits is 240, in the third octet. Mask: 255.255.240.0.
  2. Block size: 256 - 240 = 16. Subnets in the third octet start at 0, 16, 32, 48, 64, 80 and so on.
  3. 77 falls between 64 and 80. Network: 172.16.64.0.
  4. Broadcast is one less than the next subnet, with the rest all ones: 172.16.79.255.
  5. Usable hosts: 172.16.64.1 to 172.16.79.254.

Notice that 172.16.70.0 and 172.16.70.255 are ordinary host addresses in this subnet. Only the first and last address of the whole block are special.

2. How many subnets and hosts?

A company has 10.0.0.0/8 and uses /20 for every subnet. How many subnets, and how many hosts in each?

  1. Borrowed bits: 20 - 8 = 12. Subnets: 2^12 = 4096.
  2. Host bits: 32 - 20 = 12. Hosts: 2^12 - 2 = 4094.

For big powers, remember 2^10 = 1024 and double from there: 2048, 4096.

3. Which mask fits this many hosts?

A subnet must hold 50 hosts. What is the smallest subnet that fits?

  1. Find the first power of two that is at least hosts + 2. 50 + 2 = 52, and the next power of two is 64.
  2. 64 is 2^6, so 6 host bits are needed.
  3. Prefix: 32 - 6 = /26, mask 255.255.255.192, 62 usable hosts.

For 500 hosts: 512 is 2^9, so /23 with 510 hosts. Watch the edge: 30 hosts fit a /27, but 31 hosts need a /26.

4. Are these two hosts in the same subnet?

10.1.1.120/25 and 10.1.1.130/25.

/25 has a block size of 128 in the fourth octet, so the subnets are .0 to .127 and .128 to .255. 120 is in the first and 130 is in the second. They are in different subnets and need a router to talk.

This is the idea behind many troubleshooting questions. Two hosts on the same switch with a wrong mask or a wrong address cannot reach each other, or cannot reach their gateway.

5. Is this address usable?

Can 192.168.5.63/26 be given to a PC?

Block size is 64, so the subnets are .0, .64, .128, .192. The first subnet runs from .0 to .63, which makes .63 its broadcast address. It cannot be assigned. In the same way 192.168.5.64 is a network address.

With /24 these addresses would be fine. Whether an address is usable always depends on the mask.

Checking on a device

A router refuses a network or broadcast address on an interface with Bad mask /26 for address 192.168.5.63. It refuses two interfaces in the same subnet with an overlaps message.

show ip interface brief lists addresses without masks. Use show interfaces or show running-config to see the mask, and show ip route connected to see the network the router worked out from it.

Key terms

Network address
The first address in a subnet, with all host bits 0.
Broadcast address
The last address in a subnet, with all host bits 1.
Borrowed bits
Host bits turned into network bits to make more, smaller subnets.
Block size
The gap between subnet numbers in the interesting octet.
Usable range
Every address between the network address and the broadcast address.
Overlap
Two subnets that share some addresses; a router will not accept both.

For the exam

  • 1.6: configure and verify IPv4 addressing and subnetting. Expect several questions that depend on it, including troubleshooting ones.
  • The broadcast address is always one less than the next network address.
  • For "how many hosts" add 2 before picking the power of two; for "how many subnets" do not.
  • When the interesting octet is the second or third, the octets after it are 0 in the network address and 255 in the broadcast address.

Common mistakes

  • Doing the block-size maths in the wrong octet. For /20 the blocks are in the third octet, not the fourth.
  • Picking a mask that holds exactly the number of hosts and forgetting the two reserved addresses. 30 hosts fit a /27; 31 do not.
  • Assuming an address ending in .0 or .255 is never usable. In 172.16.64.0/20, the address 172.16.70.255 is a normal host.

Quick check

1. Which subnet contains the host 192.168.10.100/27?

  1. 192.168.10.64
  2. 192.168.10.96
  3. 192.168.10.100
  4. 192.168.10.128
Show the answer

B. 192.168.10.96

/27 has a block size of 32: .0, .32, .64, .96, .128. 100 falls between 96 and 128, so the network is 192.168.10.96 and the broadcast is .127.

2. What is the broadcast address of 10.20.30.40/21?

  1. 10.20.30.255
  2. 10.20.32.255
  3. 10.20.31.255
  4. 10.20.39.255
Show the answer

C. 10.20.31.255

/21 puts 248 in the third octet, a block size of 8. 30 falls in the block 24 to 31, so the network is 10.20.24.0 and the broadcast is 10.20.31.255.

3. A subnet needs 120 hosts. What is the longest prefix that fits?

  1. /24
  2. /26
  3. /25
  4. /27
Show the answer

C. /25

120 + 2 = 122, and the next power of two is 128, which is 2^7. Seven host bits means /25, with 126 usable hosts. A /26 only holds 62.

4. PC-A is 172.16.5.200/23 and PC-B is 172.16.4.10/23. Are they in the same subnet?

  1. Yes, both are in 172.16.4.0/23
  2. No, PC-A is in 172.16.5.0/23
  3. No, a /23 cannot be used on a LAN
  4. Only if the gateway is 172.16.5.1
Show the answer

A. Yes, both are in 172.16.4.0/23

/23 has a block size of 2 in the third octet: 0, 2, 4, 6. Both 4 and 5 fall in the block that starts at 4, so both hosts are in 172.16.4.0/23, which runs to 172.16.5.255.

5. Which address can be assigned to a host with the mask 255.255.255.240?

  1. 192.168.1.32
  2. 192.168.1.47
  3. 192.168.1.63
  4. 192.168.1.33
Show the answer

D. 192.168.1.33

The block size is 16. .32 is a network address, .47 and .63 are broadcast addresses. .33 is the first usable host in 192.168.1.32/28.
